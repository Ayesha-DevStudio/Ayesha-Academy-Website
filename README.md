# Ayesha's  Academy Website

A fully responsive front-end website for an online educational academy, built using **HTML, CSS, and Bootstrap 5**.

## 📚 Description

**Ayesha's Academy** is a modern educational platform website designed to showcase courses, services, student reviews, FAQs, and contact information in a clean and responsive layout.

This project was created to practice and demonstrate front-end web development skills, particularly **Bootstrap components, responsive layouts, carousels, accordions, cards, navigation bars, and custom CSS styling**.

🚀 **[Click here to view the live website](https://ayesha-academy.netlify.app/)**

## ✨ Features

* **Responsive Design:** Built with Bootstrap to provide a responsive experience across desktops, tablets, and mobile devices.
* **Navigation Bar:** Easy navigation to Home, About, Services, Reviews, FAQs, and Contact sections.
* **Image Carousel:** Interactive homepage carousel showcasing the academy.
* **Services Section:** Highlights programs such as:

  * Web Development
  * Game Development
  * Graphic Designing
* **Student Reviews:** Interactive testimonial carousel displaying student feedback.
* **FAQ Section:** Collapsible accordion panels for frequently asked questions.
* **Booking Section:** A dedicated section for users interested in academy services.
* **Guarantee & Features:** Highlights key benefits and features of the academy.
* **Contact Section:** Includes academy information and social links.
* **Custom Styling:** Additional CSS styling for cards, hover effects, review sections, backgrounds, and other visual elements.
